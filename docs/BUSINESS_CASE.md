# 처리시간·API 원가·재고 효율 사업성 모델

2026-10-17 · TEL-069. **실측 / 로그 기반 추산 / 가정 / 미래 검증**을 분리한다. 수동 처리 실측과 최신코드 REAL 3건 계측은 아직 없으며 이번 기능은 이를 기록할 도구다. 재고 최소화·수익 증가·ROI를 달성했다고 주장하지 않는다.

## 1. 수동 대비 시간 단축 시나리오

수동 흐름을 고객·기존 약속 찾기→직원/장비 가용성 대조→준비·이동·후속 약속 확인→대안 선택→공유/저장으로 나눠 **5/10/15분** 시나리오를 둔다. 현업 시간조사에 의한 예측모형이 아니라 미실측 민감도다. 플랫폼 **건당1분,3건3분**은 향후 실험에 대입할 계획 가정이며 현재3건 실측 결과가 아니다. 앞선 서버 단건16초·25초 사례를 일반 평균으로 확대하지 않는다.

| 수동 가정/건 | 플랫폼 가정/건 | 절감/건 | 시간 감소율 | 월 확보 시간(변경10건/일×22일) |
|---:|---:|---:|---:|---:|
| 5분 | 1분 | 4분 | 80.0% | 14.7시간 |
| 10분 | 1분 | 9분 | 90.0% | 33.0시간 |
| 15분 | 1분 | 14분 | 93.3% | 51.3시간 |

`개선율=(수동 전체시간−플랫폼 전체시간)/수동 전체시간`. 같은 시작/종료·품질·원문/데이터·저장 조건으로 측정하고 사람 확인·실패·보류/재입력도 포함한다. 건당 가정은 묶음 동시접수/순차처리시간과 다르다. 실제3건 비교는 수동 묶음T_manual, 플랫폼 묶음T_platform으로 다시 계산한다. 확보 시간은 인원 감축/현금 절감과 같지 않다.

## 2. 1회 처리의 API 비용

**공식 사실:** 2026-10-17 [Terra 모델 가격](https://developers.openai.com/api/docs/models/gpt-5.6-terra), [표준 가격표](https://developers.openai.com/api/docs/pricing)를 열어 재확인. short-context 1M토큰당 입력$2 / 캐시입력$0.20 / 출력$12, 캐시쓰기 입력의1.25배($2.50). 가격정책은 코드 `openai-standard-2026-10-17-terra`. 일반 표준 endpoint 기준이며 세금·환전수수료/별도 서비스등급은 포함하지 않는다.

`호출비용USD=[(입력−캐시읽기−캐시쓰기)×2 + 캐시읽기×0.2 + 캐시쓰기×2.5 + 출력×12]/1,000,000`.
쓰기 수량을 따로 모르면 실제 청구 대조가 필요하며 음수/중복 토큰으로 계산하지 않는다. 추출/설명/실패·재시도 등 과금된 모든 호출의 합이 처리 원가다. 분모는 접수건수와 성공건수를 각각 표시한다. 실패가 많으면 **성공1건당 원가**가 오른다.

**제공된 운영 로그 추산:** 실제청구 영수증이 아닌 usage×단가이며 캐시쓰기를 별도로 식별하지 못했다. 해석+설명이 모두 있는3쌍만 계산했다. 설명은 입력659/출력37/캐시0이었고 입력에출력토큰을중복포함하지않는다.

| 요청 로그 | 해석 입력/캐시읽기/출력 | 해석+설명 추산USD |
|---|---|---:|
| REQ-01-4147 | 2047 / 0 / 234 | 0.0086640 |
| REQ-02-9528 | 2047 / 1083 / 234 | 0.0067146 |
| REQ-01-e129 | 2046 / 1083 / 234 | 0.0067126 |

성공 로그3쌍의 범위 **약$0.0067~0.0087/건**이다. 실패한4회 해석도 공짜가 아니며 이 성공쌍 표에서 빠졌으므로 운영 전체의 성공당 원가로 사용하지 않는다. 캐시쓰기·추가출력·다른 원문·변경프롬프트에서는 달라진다. 현재 UI시간 내보내기는 토큰/원장 청구를 제공하지 않으므로 request ID로 별도 대조한다.

**월 예산 가정:** 새 요청의 입력2250/출력300, 설명 입력700/출력150, 캐시읽기 할인없음 가정이면$0.0113/건. 입력2950전체에 쓰기1.25배를 적용하면$0.012775. 평균시도1.1배 여유를 적용한$0.0140525를 올림해 **계획단가$0.015/건**을 사용한다. 이는 미래 예산 예시이고 상한/보장/실청구가 아니다. 실제 retry율·설명 사용률·성공률·출력량을 측정해 갱신한다.

| 일 변경 요청(가정) | 월 요청(22일) | 월 AI API 예산($0.015/건) |
|---:|---:|---:|
| 10건 | 220건 | $3.30 |
| 30건 | 660건 | $9.90 |
| 100건 | 2,200건 | $33.00 |

3건 묶음은$0.045 가정이다. 30건/일과30묶음/일(90건)을 혼동하지 않는다. 직원12명·평일25~34개 현장업무는 변경 요청 건수가 아니다. solver·검증·저장·SYSTEM 고객안내문에는 추가 OpenAI 호출이 없지만 서버/DB/운영비는 든다. AI설명을 생략하면 그 호출 비용은 줄지만 검토시간/이해도 효과도 따로 측정한다.

**예약과 사용료 구분:** 코드 사전예약은 Terra 해석 시도당$0.064, 설명1회$0.052다. 해석 내부최대2시도+설명1회는 예약상한 합$0.180/요청이며 매번 이 금액이 청구되는 것이 아니다. 성공하면실usage로정산, 불명호출은예약유지. 사람의 명시 재시도까지 포함한 전체 작업은 더 커질 수 있다. 모델예산 자동증액 없음. 위 월예산의 평단$0.015를 예약상한으로 대체하지 않는다.

## 3. ROI — 현금효과와 시간 가치를 분리

원가: API+서버/DB/스토리지/백업·모니터링+교육/데이터이관+유지보수/지원. 프리티어·해커톤 크레딧을 장기0원으로 가정하지 않는다. SaaS 구독료를 고객원가로 넣는 경우 그 안의 공급자 API/서버비를 다시 더해 중복 계산하지 않는다. 개발비/도입비는 별도 초기투자I로 둔다.

- 시간가치(참고)=월 확보 시간×실제 총인건비/시간. 급여가그대로이면현금절감아님.
- 실현된 월편익B=실제줄어든초과근무/외주비+추가완료한대여의**매출이아닌공헌이익**+검증된재고보유/긴급운송비감소. 같은업무시간에대해인건비와추가처리이익을중복계산하지않는다.
- 월순편익=B−반복운영비C. 회수기간=I/(B−C), B≤C이면회수기간을산출하지않는다.
- 기간ROI=(기간실현편익−기간반복운영비−초기투자)/(기간반복운영비+초기투자)×100.
- 경제적잠재가치는시간가치를포함할수있지만현금ROI와명확히분리한다.

**전부 가정인 산술 예:** 수동10분→플랫폼1분,220건/월이면33시간. 시간당2만원 가정→잠재시간가치66만원/월. 이중50%를실제초과근무·외주비절감으로실현한다고가정하면33만원/월(실측전).
API$3.30×**가정환율1,400원/$**=4,620원; 기타반복비월10만원가정→C=104,620원. 초기투자100만원가정이면월순편익225,380원,회수약4.44개월,12개월ROI약75.6%. 실제환율·견적·인건비·회수실적이아니며가정이바뀌면결론이달라진다. 실현율0이면현재인건비항목현금편익0, API+운영비만발생한다. 재고효과는이예에아직넣지않았다.

## 4. 사업 비전: 더 적은 재고로 같은 약속을 지킨다

**제안 문구:** “장비를 더 사기 전에, 이미 가진 장비와 직원의 일정을 최적화합니다. 회수·준비·재납품을 연결해 같은 재고로 더 많은 고객의 약속을 지키는 렌탈 운영 플랫폼입니다.”

현재증거는작업조건검증·국소재배치·동일모델대체·직원/퀵·다음근무일제안이다. 수요예측·장기배차·재고구매량의전역최적화·수학적최소보유량증명은구현되지않았다. 당장재고를줄이라는권고를하지않는다. 안전재고·고장·동일시점수요·준비/이동·주말/숙련조건이필요하다. 퀵을늘려재고만줄이는안이총비용을늘리지않는지도본다.

| 검증할 지표 | 정의와 비교 조건 |
|---|---|
| 약속 준수율 | 같은 수요/장비/근무/제약에서 기한내 완료가능한요청÷전체요청. 미지원·실패·보류를숨기지않음 |
| 가동률 | 장비별 실제대여가능시간 대비 대여중시간(준비·고장·이동상태와분모정의를고정), 단순보유대비예약건수와구분 |
| 장비당 공헌이익 | 기간대여매출−변동원가를평균운영장비수로나눔. 이동/준비·퀵비포함 |
| 추가 구매 회피 | 동일수요·동일서비스수준에서기존정책필요장비−최적화정책필요장비. 구매계획·품목별차이·증빙필요 |
| 회수→다음 출고 회전시간 | 회수완료부터준비완료·다음사용까지. 현장완료실시간기록미구현이므로현재계획상지표와실적을구분 |
| 총운영비/성공 대여 | 재고보유비+인력/초과근무+이동/퀵+시스템비를품질통과대여수로나눔 |

후속실험은동일한동결수요를품목별보유량100/95/90% 등에서재생하고, 최소기한준수율·하드제약·고장안전여유를고정해곡선을만든다. 단순가동률상승이좋은것은아니며급한수요를수용할여유도본다. 아직미지원수요는제외사유/분모를공개한다. C의독립평가자료를개발튜닝용으로읽지말고별도미래실험세트를만든다.

**가정 예:** 장비132대중동일품목구매10대를피하고대당취득가100만원이면초기현금유출회피1,000만원. 이는확인된절감이아니다. 취득현금흐름모형과월감가/보유비모형을별도로쓰며1,000만원을매월편익으로더하거나같은구매의감가와중복계상하지않는다. 이미산유휴장비의장부가를현금회수로보지않는다. 미래발표는“재고X%감축에도약속준수Y%,총운영비Z%개선”을동일조건검증후에만사용한다.
